Assigning Administrative Roles

Tout le monde ne doit pas pouvoir tout faire sur un routeur. Ce module montre comment limiter les commandes disponibles avec les niveaux de privilège, puis, plus finement, avec le CLI basé sur les rôles (vues et superviews).
